## 0.1.0

- Initial release: file and directory selection with random-access byte reads.
- Android SAF file descriptors, Apple security-scoped access, desktop files and browser blobs.
- Recursive directory traversal with relative paths.
- Access restoration through persisted URI permissions, bookmarks, paths and supported browser directory handles.
- Paged binary viewer example, diagnostic app and synthetic CUE/BIN fixtures.
- Requires Flutter 3.38+ and Dart 3.10+ to match the file_picker dependency.
